# African programme IB requirements — final review 2026-09-16

Artifact: `data/sources/ib-requirements-africa-20260915.json` (`official-ib-africa-2026-09-16-r2`). Initial research: 2026-09-15; final review and all source `checkedOn` dates: 2026-09-16.

Six programme-specific IB recognition records across four institutions in Kenya, Tanzania, and Nigeria. None of the reviewed sources supplies a numeric IB total for these routes. All six therefore retain `status: "not_stated_in_source"` and null scores; recognition is not converted into an invented minimum, including a default 24 points.

Preserve this lead for explicit faculty-scope support or separate programme-level verification. It was never imported by this batch and was not deleted from the database.
